# Реєстр «написано, але не перевірено наживо»

Оновлюється кожен блок. Знімається пункт лише після живого прогону на деплої.

## Заблоковано Блоком 0 (немає деплою)
- Повний цикл: реєстрація → створення весілля → редактор → оплата Monobank → публікація.
- Дашборд наживо: всі вкладки (Дизайн/Деталі/Гості/Відповіді/Медіа/Фото/Поділитися/Перегляд).
- Вкладка «Відповіді»: реальні RSVP у зведеннях і CSV.
- Захист паролем: форма гостя, cookie, повторний вхід.
- QR: генерація і завантаження PNG.
- Save the Date: сторінка /std/[slug], тема з template_id, .ics в Apple/Google/Outlook, шерінг-прев'ю.
- i18n наживо: geo-cookie, словник у Field & Serif і Le Voyage на реальному рендері.
- Схема БД проти реального коду: створення весілля через /api/weddings (можливі відсутні колонки), guests-flow (invite/токени).

## Відомі свідомі спрощення
- OG-картинка для /std поки стандартна (динамічну з ImageResponse відкладено — потребує живого прогону шрифтів з кирилицею).
- STD без пароля за дизайном (лише імена/дата/місто).
- Мультиподійного RSVP ще немає (Блок за роадмепом).
